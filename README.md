# Треугольная триангуляция и морфинг лиц

Этот проект использует алгоритмы триангуляции Делоне для работы с изображениями лиц. Он включает в себя функции для морфинга лиц между двумя изображениями с использованием аффинных преобразований.

## Требования

Для работы этого проекта потребуется установить следующие библиотеки Python:

- OpenCV
- NumPy
- cvzone (для обнаружения лиц)

Установить их можно с помощью pip:

```bash
pip install opencv-python numpy cvzone
```

## Описание функций

### Основные функции

1. **`create_subdiv(image)`**: Создает объект для подтипа `Subdiv2D`, который используется для вычисления триангуляции Делоне.

2. **`create_delaunay(image, subdiv, points, animate=False)`**: Выполняет создание триангуляции Делоне для заданных точек на изображении. Возможность анимации процесса через параметр `animate`.

3. **`draw_delaunay(img, subdiv, delaunay_color)`**: Рисует триангуляцию Делоне на изображении с указанным цветом.

4. **`create_voronoi(img, subdiv)`**: Рисует диаграмму Вороного на изображении.

5. **`get_control_points(face, out, draw=True, maxFaces=1)`**: Извлекает контрольные точки лица с использованием FaceMeshDetector из библиотеки cvzone.

6. **`create_morph(img1, img2, imgMorph, alpha, coords, coords2, replace_face=False)`**: Создает морфинг между двумя изображениями с учетом контрольных точек и альфа-пропорции для плавного перехода.

7. **`applyAffineTransform(src, srcTri, dstTri, size)`**: Применяет аффинное преобразование для треугольников на изображении.

8. **`screen_normalizator(to_same_resolution, *images)`**: Нормализует изображения до одного размера.

### Дополнительные функции

- **`catch_face(img)`**: Обрабатывает изображение для захвата и обработки лица, рисует триангуляцию и диаграмму Вороного.

- **`face_mask(img1, img2, alpha)`**: Применяет маску на изображение для морфинга лица между двумя изображениями.

- **`create_del_vor(path, animate=False)`**: Создает триангуляцию Делоне и диаграмму Вороного для изображения, загружаемого по указанному пути.


## Пример использования

Пример использования функции `main()` для морфинга двух изображений:

```python
main("image1.jpg", "image2.jpg", alpha=0.5, to_same_resolution=True, using_alpha=True)
```

- `path1` и `path2`: Пути к изображениям, которые будут использованы для морфинга.
- `alpha`: Альфа-пропорция, которая определяет степень смешивания двух изображений (от 0 до 1).
- `to_same_resolution`: Признак того, нужно ли привести изображения к одинаковому разрешению перед морфингом.
- `using_alpha`: Признак того, использовать ли фиксированную альфа-пропорцию или линейную.
